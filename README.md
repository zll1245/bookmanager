# 图书管理系统（Book Management System）

## 📚 项目简介

本项目是一个基于 **C++ + MFC + ODBC + MySQL** 开发的图书管理系统，支持图书信息的录入、查询、借还、销售、库存管理等操作，适用于图书馆或书店场景。

系统提供管理员和普通用户两种角色，分别具备不同权限，实现了基本的图形化用户界面，数据持久化存储在 MySQL 数据库中。

## 🛠️ 功能模块

- ✅ 用户登录（管理员 / 普通用户）
- 📖 图书信息管理：添加、修改、删除、查询
- 🛒 图书销售与进货记录管理
- 📦 库存管理与库存统计
- 🔎 借阅 / 归还图书操作（支持查询历史）
- 📑 提供图书分类管理与供应商信息管理
- 🧾 销售与库存统计报表生成


## 🧱 技术栈

- **语言**：C++
- **图形界面**：MFC（Microsoft Foundation Classes）
- **数据库**：MySQL
- **数据库连接**：ODBC
- **开发工具**：Visual Studio 2022、Qt Designer（可选用于 UI 原型）
- **版本控制**：Git + GitHub
